TRAVERSE PATH - UNITY 6

Scripts:
- TraversePathGame.cs
- MazeGenerator.cs
- PathPlayer.cs
- PathVisual.cs
- FingerGuide.cs

Setup:
1. Create a new Unity 6 2D project.
2. Create an empty GameObject named TraversePathGame.
3. Add TraversePathGame.cs.
4. Optional: create a Player sprite and assign it to playerSprite; create a finger/hand sprite and assign to fingerSprite.
5. Press Play. The system creates a portrait maze, 10 procedural levels, dotted solution path, glow path, player, finger guide, progress UI, retry and next-level buttons at runtime.
6. For Android set portrait orientation in Player Settings. Touch works; mouse works in Editor.

No external package or paid asset is required.
